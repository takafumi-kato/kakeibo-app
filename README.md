# 家計簿アプリ

JavaScriptを使用して制作した家計簿アプリです。

## 概要

収入・支出を登録し、現在の収支状況を管理できるWebアプリです。

## 機能

- 収入・支出の登録
- 取引データの一覧表示
- 取引データの編集
- 取引データの削除
- 収入・支出・残高の計算
- 年月による検索
- 金額の桁区切り表示
- localStorageによるデータ保存

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

## 工夫した点

JavaScriptでDOM操作を行い、登録・編集・削除した内容を画面にリアルタイムで反映できるようにしました。

また、localStorageを使用して、ブラウザを更新しても登録した家計簿データが保持されるようにしています。
